# Skills

A collection of GitHub CLI skills and workflows.

## About

This repository contains a curated set of GitHub CLI skills and workflows designed to help developers automate and streamline their development processes. Each skill is a self-contained guide that teaches how to perform common GitHub tasks programmatically.

## Available Skills

| Skill | Description |
|-------|-------------|
| [gh-tasks](gh-tasks/SKILL.md) | Use the GitHub CLI to perform GitHub tasks — repositories, issues, pull requests, gists, releases, and git operations |
| [vue-best-practices](vue-best-practices/SKILL.md) | Vue.js best practices using Composition API with `<script setup>` and TypeScript |
| [work-on-issue](work-on-issue/SKILL.md) | Start work on a OneDev issue: create the issue branch, switch checkout, read issue details |
| [submit-work](submit-work/SKILL.md) | Submit completed work on a OneDev issue: commit, push, and open a pull request |
| [using-tod](using-tod/SKILL.md) | Drive OneDev workflows via the `tod` CLI — issues, PRs, builds, and more |
| [standup-report](standup-report/SKILL.md) | Generate standup reports from OneDev activity for PRs and issues |
| [review-pull-request](review-pull-request/SKILL.md) | Review pull requests via `tod pr get`, `tod pr get-patch`, and related commands |
| [tod-skills-readme](tod-skills-readme/SKILL.md) | Umbrella guide for any OneDev interaction via `tod` |
| [golang-code-style](golang-code-style/SKILL.md) | Go code style conventions — line length, variable declarations, control flow |
| [investigate-build-failure](investigate-build-failure/SKILL.md) | Debug a failing build via `tod build get`, `tod build get-log`, and related commands |
| [edit-build-spec](edit-build-spec/SKILL.md) | Create or update `.onedev-buildspec.yml` using `tod build get-spec-schema` |
| [generate-commit-message](generate-commit-message/SKILL.md) | Compose a commit message respecting `tod get-commit-message-requirement` |
| [edit-build-spec](edit-build-spec/SKILL.md) | Create or update `.onedev-buildspec.yml` |
